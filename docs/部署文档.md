# API 自动化测试平台 · Linux 部署文档

> 本文档说明如何将本平台部署到 Linux 服务器（以 Ubuntu/Debian 为例，CentOS 仅安装命令略有差异）。

---

## 一、部署架构

```
                        互联网
                          │
                    ┌─────▼─────┐
                    │   Nginx   │  (80/443 端口)
                    └─────┬─────┘
              ┌───────────┴───────────┐
    静态文件（前端）              反向代理 /api
     /usr/share/api-web/client/dist   │
                          ┌───────────▼───────────┐
                          │  Node.js 后端 (PM2)   │  (4000 端口)
                          │  Fastify + Prisma     │
                          └───────────┬───────────┘
                                      │
                              ┌───────▼───────┐
                              │  SQLite 文件   │
                              │  (server/prisma/dev.db)
                              └───────────────┘
```

- **前端**：Vite 构建成纯静态文件，交给 Nginx 托管
- **后端**：Node.js 进程（用 PM2 守护），监听 4000 端口
- **数据库**：SQLite 单文件，无需单独安装数据库服务
- **Nginx**：同时托管前端静态文件 + 把 `/api` 请求反向代理到后端

## 二、环境准备

### 2.1 安装 Node.js 20+

推荐用 nvm 管理（方便升级/多版本）：

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc

# 安装 Node 20 LTS
nvm install 20
nvm use 20
nvm alias default 20

# 验证
node -v   # 应显示 v20.x.x
npm -v
```

> 或使用系统包安装：`curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt-get install -y nodejs`

### 2.2 安装 Nginx

```bash
sudo apt-get update
sudo apt-get install -y nginx
sudo systemctl enable nginx
```

### 2.3 安装 PM2（后端进程守护）

```bash
sudo npm install -g pm2
```

### 2.4 安装 Git（如需从仓库拉取代码）

```bash
sudo apt-get install -y git
```

## 三、获取代码

**方式一：Git 拉取**（推荐，方便后续更新）

```bash
cd /opt

```

```bash
# 本地打包（排除 node_modules 和构建产物）
# 在本地项目根目录执行：
#   tar --exclude='node_modules' --exclude='dist' --exclude='dev.db' -czf api-web.tar.gz .

cd /opt

tar -xzf api-web.tar.gz -C api-web

```

## 五、配置环境变量

后端需要两个环境变量，写入 `server/.env`：

```bash
cd /opt/api-web
cat > server/.env << 'EOF'
DATABASE_URL="file:./dev.db"
PORT=4000
HOST=127.0.0.1
EOF
```

**说明**：

| 变量 | 默认 | 说明 |
|---|---|---|
| `DATABASE_URL` | `file:./dev.db` | SQLite 数据库文件路径 |
| `PORT` | 4000 | 后端监听端口 |
| `HOST` | 127.0.0.1 | 监听地址（用 127.0.0.1 仅本机可访问，由 Nginx 代理，更安全） |

> 生产环境建议 `HOST=127.0.0.1`，后端不直接暴露公网，只通过 Nginx 访问。

## 六、初始化数据库

```bash
cd /opt/api-web/server

# 应用数据库迁移（生产环境用 deploy，不交互）
npx prisma migrate deploy

# 验证迁移成功（会列出已应用的迁移）
npx prisma migrate status
```

执行后会在 `server/prisma/` 下生成 `dev.db` 数据库文件。

## 七、构建

```bash
cd /opt/api-web

# 构建后端（编译 TS → server/dist）

# 构建前端（打包 → client/dist）
npm run build -w @api-web/client
```

- 后端：`server/dist/`
- 前端：`client/dist/`

## 八、启动后端（PM2 守护）

```bash
cd /opt/api-web/server

# 启动（生产模式运行编译产物）
pm2 start dist/index.js --name api-web-server

# 设置开机自启
pm2 save
pm2 startup   # 按提示执行输出的命令

# 查看状态
pm2 status
pm2 logs api-web-server   # 查看日志
```

**验证后端**：

```bash
curl http://127.0.0.1:4000/api/health
# 应返回 {"status":"ok","service":"api-web-server"}
```

## 九、配置 Nginx

### 9.1 创建站点配置

```bash
sudo vim /etc/nginx/sites-available/api-web
```

写入以下内容（替换 `your-domain.com` 为你的域名或服务器 IP）：

```nginx
server {
    listen 80;
    server_name your-domain.com;   # 域名或服务器 IP

    # 前端静态文件
    root /opt/api-web/client/dist;
    index index.html;

    # 前端路由（SPA）回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:4000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;   # 场景执行可能较久，延长超时
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|svg|ico|woff2?)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
}
```

### 9.2 启用站点并重载

```bash
sudo ln -s /etc/nginx/sites-available/api-web /etc/nginx/sites-enabled/
sudo nginx -t           # 检查配置语法
sudo systemctl reload nginx
```

### 9.3 防火墙放行 80 端口

```bash
sudo ufw allow 80/tcp        # Ubuntu
# 或 CentOS：sudo firewall-cmd --permanent --add-port=80/tcp && sudo firewall-cmd --reload
```

## 十二、常见问题 FAQ

**Q1：curl 后端 health 正常，但通过域名访问 /api 返回 502？**
后端进程没启动或 PM2 崩溃。检查：`pm2 status`、`pm2 logs api-web-server`。

**Q2：前端页面空白 / 刷新后 404？**
Nginx 的 `try_files $uri $uri/ /index.html` 未配置，导致 SPA 路由刷新 404。按 9.1 配置。

**Q3：数据库迁移报错？**
确认 `server/.env` 的 `DATABASE_URL` 路径正确，且以 `server` 目录为工作目录运行 migrate。

**Q4：如何修改后端端口？**
改 `server/.env` 的 `PORT`，同时改 Nginx `proxy_pass` 的端口，然后 `pm2 restart`。

**Q5：如何配置 HTTPS？**
用 Let's Encrypt（certbot）：
```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

**Q6：数据备份？**
数据库就是 `server/prisma/dev.db` 单个文件，直接备份该文件即可：
```bash
cp /opt/api-web/server/prisma/dev.db /backup/dev-$(date +%F).db
```

## 十三、附：用 systemd 替代 PM2（可选）

如果不想用 PM2，可用 systemd 管理后端进程：

```bash
sudo vim /etc/systemd/system/api-web-server.service
```

```ini
[Unit]
Description=API Web Server
After=network.target

[Service]
Type=simple
User=你的用户名
WorkingDirectory=/opt/api-web/server
Environment=DATABASE_URL=file:./dev.db
Environment=PORT=4000
ExecStart=/usr/bin/node dist/index.js
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now api-web-server
sudo systemctl status api-web-server
```
