## 二、顶部全局配置栏

顶部配置栏包含三个入口：设置全局变量、调试记录、回收站。三个入口以图标+文字形式展示，右侧可显示当前项目名称与当前登录用户信息（悬停展示权限角色），通过分割线与下方业务三栏隔离。

### 2.1 设置全局变量

#### 2.1.1 变量优先级规则

遵循 MeterSphere 变量优先级逻辑，优先级从高到低：

临时调试变量 > 任务执行变量 > 环境变量 > 全局变量

各优先级说明：

优先级 1（最高）：临时调试变量
- 作用域：单次调试会话
- 生命周期：调试弹窗关闭即失效
- 典型场景：调试时临时覆盖某个值

优先级 2：任务执行变量
- 作用域：单次任务执行
- 生命周期：任务执行期间有效
- 典型场景：任务中通过前置脚本动态生成 token 并传递

优先级 3：环境变量
- 作用域：指定环境
- 生命周期：环境配置持久有效
- 典型场景：不同环境 baseURL、账号密码

优先级 4（最低）：全局变量
- 作用域：全项目
- 生命周期：持久有效
- 典型场景：项目通用配置，如 appKey

变量覆盖规则：同名变量执行时高优先级自动覆盖低优先级，并在调试/执行日志中标注变量来源及覆盖关系。

#### 2.1.2 变量类型支持

字符串：普通文本，示例：hello
数字：整数或浮点数，示例：100、3.14
布尔：true / false，示例：true
时间戳：自动生成当前时间戳（支持毫秒/秒格式切换），示例：1700000000000
随机函数：内置随机数生成函数，示例：${__RandomString(8)}
密钥类型：后台 AES-256 加密存储，界面统一以 ****** 脱敏展示，点击眼睛图标可临时查看（需二次确认），典型场景为 API Key、密码

#### 2.1.3 变量引用语法

全平台统一采用 ${变量名} 引用语法，支持以下位置：

- 请求 URL、路径参数、Query 参数
- 请求头（含 Authorization、Cookie 等）
- 请求体（JSON/XML/form-data）
- 前置/后置脚本（JS/Python）
- 断言表达式
- Mock 响应内容
- 流程控制器条件表达式

补充规则：

- 变量不存在时，执行日志警告提示，原样保留 ${变量名} 字符串或替换为空（用户可配置）。
- 嵌套变量支持：${env_${system}} 解析为内层变量先解析、外层变量后解析。
- 提供变量预览功能：在变量管理页面，可输入变量表达式，实时预览解析结果。

#### 2.1.4 变量管理操作

新增：填写变量名、类型、值、描述；变量名校验规则：字母/数字/下划线，不能以数字开头。
编辑：修改值、类型、描述；密钥类型编辑时需先解密验证。
删除：支持单个删除、批量删除；删除前检查引用关系，提示引用位置。
批量导入：支持 Excel/CSV 导入，提供模板下载。
批量导出：导出为 Excel/JSON；密钥类型导出时加密展示。
批量替换：按变量名或变量值搜索，批量替换；支持正则匹配。
引用追踪：查看某变量被哪些用例、接口、脚本引用。


### 2.2 调试记录

#### 2.2.1 记录范围与筛选

全局存储全部用例的调试记录，与中间面板 Tab-2 的单用例调试记录形成"全局/局部"双层视图。

筛选条件：

- 用例名称：模糊搜索
- 执行环境：下拉选择，动态展示已配置环境
- 执行结果：全部 / 成功 / 失败 / 跳过
- 执行方式：本地调试 / 服务端调试 / 定时任务 / CI 触发
- 时间范围：支持今天、近3天、近7天、近30天、自定义区间
- 执行人：按操作人筛选

#### 2.2.2 记录完整信息

每条调试记录保存以下完整信息：

- 基础信息：调试时间、用例名称、执行环境、执行方式、执行耗时（总耗时+单步骤耗时）、执行人
- 请求详情：每个步骤的请求方法、完整 URL（含变量替换后的实际值）、请求头、请求参数、请求体
- 响应详情：状态码、响应头、响应体、响应大小
- 断言结果：每条断言的通过/失败状态、失败原因、预期值 vs 实际值
- 提取变量：提取的变量名、提取值、提取来源
- 执行状态：成功 / 失败 / 跳过（跳过原因）
- 错误日志：异常堆栈、错误描述

#### 2.2.3 调试记录操作

查看详情：展开完整请求/响应/断言信息，JSON/XML 自动格式化展示。
一键重放调试：基于原调试记录的环境与参数重新执行调试，生成新记录（不覆盖原记录）。
快速生成用例：基于调试记录中的步骤信息，一键生成新用例并添加到指定目录。
对比差异：任选两次调试记录，对比请求参数、响应体、断言结果、提取变量、执行耗时的差异，差异部分高亮展示。
删除：支持单条删除、批量删除；支持按时间范围清理。


### 2.3 回收站

#### 2.3.1 回收对象与信息展示

回收对象及展示信息：

目录：目录名称、父级路径、包含用例数、删除人、删除时间
接口定义：接口名称、所属模块路径、请求方式、URL、删除人、删除时间
接口用例：用例名称、所属目录路径、删除人、删除时间
测试任务：任务名称、任务类型（普通任务/定时任务）、删除人、删除时间

#### 2.3.2 操作与策略

还原：单个还原或批量还原；若原目录已被删除，则还原到根目录并提示；若存在同名冲突，提示重命名。
永久删除：二次确认弹窗；永久删除不可恢复；批量删除需输入确认文字。
自动清理：可配置自动清理周期：7天 / 15天 / 30天 / 60天 / 不自动清理；到期数据在每日凌晨定时任务中自动清除。
存储策略：回收站数据保留期间不计入项目数据配额。


## 三、左侧：用例库板块

### 3.1 原有能力（保留）

- 顶部名称搜索框模糊检索
- 支持新建多级目录，按业务模块归类用例
- 点击用例，中间面板加载用例详情

### 3.2 新增能力（对标 MeterSphere）

#### 3.2.1 目录树右键菜单

右键目录节点支持的操作：

新建子目录：在当前目录下创建子目录。
新建用例：在当前目录下创建新用例。
重命名：修改目录名称。
复制目录：深度复制整个目录及下属所有用例到指定位置。
移动目录：移动目录及下属所有用例到目标位置。
删除目录：弹窗选择——仅删除目录（子内容移入上级）或同步删除所有下属用例（进入回收站）。
导出目录：导出该目录下所有用例（JSON 格式）。

右键用例节点支持的操作：

编辑：在中间面板打开用例。
复制用例：复制到指定目录，可选择是否复制历史版本。
移动用例：移动到目标目录。
删除用例：删除到回收站。
禁用/启用：快速切换用例状态。
添加标签：快速打标签。
提交评审：提交用例评审。

#### 3.2.2 用例版本管理

版本快照：每次保存用例后自动生成版本快照（版本号 + 时间戳 + 保存人）；支持手动保存为命名版本（如 v1.0.0 基线版本）。
版本列表：展示所有历史版本，含版本号、保存时间、保存人、变更摘要（自动比对差异生成）。
版本回退：一键回退到任意历史版本；回退前自动保存当前版本为临时快照，可撤销回退。
版本对比：选择任意两个版本，并排展示内容差异，高亮新增/删除/修改部分。
版本删除：保留最近 N 个版本（默认 20 个，可配置），更早版本可手动清理。

#### 3.2.3 批量操作

在目录树顶部工具栏提供批量操作入口：

批量移动：选中多个用例，移动到目标目录。
批量复制：选中多个用例，复制到目标目录（支持添加前缀/后缀区分副本名称）。
批量启用/禁用：切换用例状态。
批量删除：删除到回收站，二次确认。
批量打标签：为选中的用例统一添加标签。
批量导出：导出选中用例为 JSON 文件。

#### 3.2.4 用例标签体系

自定义标签：支持创建、编辑、删除标签；标签支持颜色标记。
标签筛选：目录树顶部支持按标签筛选用例；支持多标签组合筛选（AND/OR 逻辑）。
标签场景：用于迭代分类（如 v2.1.0）、版本分类（如回归测试）、模块分类（如支付模块）、优先级分类（P0/P1/P2）。

#### 3.2.5 用例状态

草稿：编辑中，未完成；可执行，但报告中标记为"草稿"。
已完成：正式可用状态；正常执行。
已废弃：不再使用的用例；执行任务时默认跳过，报告中标记为"已废弃跳过"。

状态切换支持手动切换与自动流转（如提交评审通过后，状态自动从草稿变为已完成）。

#### 3.2.6 公共用例引用

创建公共用例：任意用例可标记为"公共用例"，存放在公共用例库中。
引用方式：在普通用例步骤中通过"引用公共用例"步骤类型引用。
引用行为：引用后作为步骤执行；支持传参覆盖公共用例中的变量；引用版本可锁定。
变更同步：公共用例更新时，引用方可收到变更通知，可选择同步更新或保持原版本。
解耦复制：支持"断开引用"，将引用的公共用例内容复制为独立步骤。


## 四、中间：编写用例板块

切割线下为用例名称编辑框，下方两个 Tab：脚本、调试记录。

### Tab-1 脚本

分为前置步骤、测试步骤、后置步骤三个区域，中间用虚线分隔，每个区域可折叠/展开。

#### 4.1 前置步骤

定位：用例执行前初始化，为测试步骤准备前置条件。

支持的步骤类型：

接口请求：执行登录、获取 token、初始化数据等接口。
自定义脚本：编写 JS/Python 脚本，进行变量赋值、数据构造。
等待：固定等待 / 条件等待（等待某变量满足条件）。
变量赋值：直接对变量赋值或通过表达式计算赋值。
引用公共脚本片段：从公共前置脚本库中选择脚本片段执行。

公共前置脚本库：

- 平台提供公共前置脚本库，存放登录、获取 token、签名计算等通用逻辑
- 支持分类管理、版本管理
- 用例前置步骤中可引用，引用时支持参数传入
- 公共脚本更新时，引用方收到变更通知

#### 4.2 测试步骤（核心）

##### 4.2.1 步骤基础操作

添加步骤：支持添加接口请求、流程控制器、自定义脚本、等待、变量赋值等步骤类型。
拖拽排序：鼠标拖拽调整步骤顺序。
启用/禁用：每条步骤左侧开关，禁用后执行时自动跳过，日志打印跳过原因。
复制/粘贴：右键复制步骤，支持跨用例粘贴（需同协议类型）。
步骤折叠：点击步骤头部折叠/展开步骤详情。
步骤备注：每条步骤支持添加备注说明。

##### 4.2.2 协议支持

HTTP/HTTPS：基础协议支持。
请求体格式：form-data、x-www-form-urlencoded、JSON、XML、文件上传、二进制流。
认证方式：无认证、Basic Auth、Bearer Token、API Key、OAuth 2.0（支持自动刷新 token）。

##### 4.2.3 接口步骤配置项

请求参数：

路径参数：URL 中使用 {param} 或 :param 标识，自动识别。
Query 参数：键值对形式，支持批量添加。
请求头：键值对形式，支持从"获取请求头"工具快速导入。
请求体：根据 Content-Type 自动切换编辑器（JSON/XML/form-data 表单）。

断言：

支持的断言类型：

状态码：断言响应状态码等于/不等于/属于范围。
响应包含/不包含：断言响应体包含/不包含指定文本。
JSONPath：断言 JSON 响应中某字段的值，支持等于/不等于/大于/小于/包含/正则匹配/类型判断。
正则：断言响应体匹配/不匹配指定正则。
XPath：断言 XML/HTML 响应中指定节点的值。
数值比较：大于/小于/大于等于/小于等于/区间判断。
空值断言：断言某字段为空/不为空。
响应时间：断言响应耗时小于等于或大于等于指定阈值。
脚本断言：自定义 JS/Python 脚本进行复杂断言。

断言配置项：

断言失败提示：自定义断言失败时在报告中展示的提示信息。
失败策略：停止用例 / 继续执行后续步骤。
断言启用开关：可临时禁用某条断言。
多条断言：无上限，按顺序执行。

响应提取：

Header 提取：从响应头中提取指定字段值。
Cookie 提取：从 Set-Cookie 中提取。
JSONPath 提取：从 JSON 响应体中提取。
正则提取：从响应体中正则匹配提取。
XPath 提取：从 XML 响应体中提取。

提取配置项：

- 变量名：提取后存储的变量名
- 默认值：提取失败时的默认值
- 提取失败策略：忽略继续 / 停止用例

##### 4.2.4 流程控制器（对标 MeterSphere 逻辑控制器）

IF-ELSE 条件判断：根据条件表达式判断执行分支；条件表达式支持 ${变量名} 引用和逻辑运算；支持添加 ELSE 分支。
FOR 循环：遍历集合执行子步骤；配置项为循环变量名、循环次数/遍历列表、步进值。
WHILE 循环：条件满足时循环执行；配置项为循环条件表达式、最大循环次数（防死循环）、循环间隔。
事务控制器：子步骤整体作为事务判断；配置项为事务名称、事务内子步骤列表、整体成功/失败判定规则。
仅一次控制器：子步骤在任务中仅执行一次；适用于登录等操作。

控制器交互说明：控制器作为容器步骤，内部可嵌套接口请求与其他控制器（支持嵌套，最大深度 5 层），容器可整体折叠/展开，整体启用/禁用。

##### 4.2.5 底部工具能力

获取请求头：从上游响应中参数化获取 token 等值，自动填充到当前步骤请求头；支持 Bearer Token、Cookie、自定义 Header 格式。
固定等待：设置固定等待时间（毫秒/秒）。
动态等待：条件等待，轮询某变量或某接口响应，直到满足条件或超时。
自定义脚本：JS/Python 脚本编辑器，支持语法高亮、代码补全；脚本可引用 ${变量名}。
IF 循环判断：快速添加 IF-ELSE 控制器。
快速断言助手：点击后自动分析最近一次响应，推荐断言项，一键添加。

#### 4.3 后置步骤

执行时机：无论用例成功还是失败，默认都会执行后置步骤。

支持的步骤类型：

接口请求：调用清理数据接口、退出账号接口。
自定义脚本：执行清理逻辑、释放资源。
变量清理：清除执行过程中产生的临时变量。
等待：固定/条件等待。

配置项：

失败忽略：后置步骤失败时是否阻断用例结果（默认忽略）。
条件执行：可配置仅在前置步骤失败/成功/全部执行时执行。
超时时间：后置步骤单独超时配置。

### Tab-2 调试记录

只展示当前这条用例对应的调试历史，过滤全局记录。

功能说明：

筛选：按执行环境、执行结果、时间范围筛选。
查看详情：展开完整请求/响应/断言信息。
一键重放：基于历史记录重新调试。
对比：选择两次记录对比差异。
删除：删除本用例的调试记录。

### 4.4 调试弹窗（选中用例自动弹出）

点击调试按钮或 Ctrl+Enter，弹出调试配置弹窗。

#### 4.4.1 调试环境配置

临时环境变量：新增、修改、删除调试临时变量；仅本次调试会话有效；弹窗关闭即失效。
选择环境：下拉选择已配置环境，用例中变量自动替换为环境变量值。
变量预览：展示用例中所有变量在当前调试环境下的实际值。
变量覆盖关系：展示同名变量各优先级取值及最终生效值。

#### 4.4.2 调试执行模式

全速运行：一次性执行完毕，展示汇总结果。
单步调试：逐步执行，每步执行后暂停，手动触发下一步。
断点调试：在指定步骤设置断点，执行到断点处暂停；暂停时可查看当前变量值、请求上下文。
跳过前置/后置：可选仅执行测试步骤（跳过前置和后置）。
失败暂停：步骤失败时自动暂停，便于排查。

#### 4.4.3 调试执行方式

本地调试：从本地机器发起请求，适合调试内网接口。
服务端调试：由平台服务端发起请求，适合调试公网接口，结果不受本地网络影响。

#### 4.4.4 实时展示

调试执行过程中实时展示：

- 当前执行到第几步、步骤名称
- 每一步的请求、响应、断言结果、变量取值
- 执行时间轴视图
- 失败步骤的错误日志和堆栈
- 变量变化追踪：展示变量值的前后变化


## 五、右侧：接口管理板块（接口定义库）

### 5.1 原有能力（保留）

- 按模块创建目录
- 手动新增接口
- Excel 导入（字段：请求方式、URL）

### 5.2 新增能力（对标 MeterSphere）

#### 5.2.1 OpenAPI/Swagger 导入

URL 导入：填写 Swagger/OpenAPI 接口文档地址，自动拉取解析。
文件上传：上传 JSON/YAML 格式文件。
自动生成：解析后自动生成模块目录（按 tag 分组）与接口定义。

导入处理规则：

- 解析接口的请求方法、URL、参数、请求体 Schema、响应示例
- 按 Swagger tag 自动创建模块目录
- 已存在的同名接口提供覆盖/跳过/新建三个选项
- 导入完成后展示导入摘要：新增 N 个接口、更新 M 个接口、跳过 K 个接口

#### 5.2.2 接口完整元信息维护

请求方式：GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS。
URL：完整 URL 或路径（支持 ${变量名} 引用）。
路径参数：自动识别并配置。
Query 参数：键值对，支持参数描述、是否必填、默认值。
请求头：键值对。
请求体：按 Content-Type 分类维护。
响应示例：支持维护多个状态码对应的响应示例（200/400/500等）。
接口描述：富文本描述，支持 Markdown。
关联标签：接口打标签分类。
负责人：接口负责人指定。

#### 5.2.3 接口同步

变更检测：定期或手动触发检测 Swagger 文档是否变更。
差异对比：展示变更前后差异——新增接口、删除接口、修改接口的字段级差异。
一键更新：确认后一键更新平台接口定义。
同步记录：保存同步历史记录。

#### 5.2.4 Mock 能力

基础 Mock：为接口配置 Mock 响应，请求 Mock 地址返回模拟数据。
条件 Mock：根据请求参数、请求头等条件返回不同的 Mock 响应。
动态 Mock：Mock 响应支持引用 ${变量名}，动态生成返回值。
智能 Mock：根据响应示例 Schema 自动生成随机模拟数据。
独立运行：Mock 服务独立运行，不依赖测试执行。
Mock 开关：每个接口的 Mock 可单独启用/禁用。
Mock 日志：记录 Mock 请求日志。

#### 5.2.5 快捷操作

一键生成用例：基于接口定义快速生成自动化用例，直接同步到左侧用例库（可选目标目录）。
批量导出：支持导出 Excel / JSON / OpenAPI 格式的接口资产。
复制接口：复制接口定义到其他模块。
接口搜索：支持按接口名称、URL、方法、标签搜索。

#### 5.2.6 导入校验

请求方式合法性：仅允许标准 HTTP 方法。
URL 合法性：URL 格式校验。
必填字段校验：缺少请求方式或 URL 的行标记错误。
错误行号：导入失败时返回错误行号及原因。
失败报告：导入完成后生成导入报告，展示成功/失败明细。

## 九、边界约束

1. 任务保存校验：任务名称不能为空，至少选择 1 条用例才允许运行。
2. 禁用步骤、废弃用例调试、任务运行统一标记为跳过，日志打印跳过原因。
3. 所有脚本、变量、断言统一使用 ${变量名} 解析语法。
4. Mock 服务独立运行，Mock 响应支持引用环境变量做动态返回。
5. 变量优先级严格执行：临时调试变量 > 任务执行变量 > 环境变量 > 全局变量。
6. 回收站数据在配置的自动清理周期到达后自动清除，不进入二次回收。
7. 循环控制器必须配置最大循环次数，防止死循环。
8. 密钥类型变量后台 AES-256 加密存储，任何接口导出均不可见明文。
9. 并行执行时，共享变量操作需加锁或声明为线程安全。
10. 所有请求均需支持 HTTPS 证书校验与忽略证书选项。
11. 单次任务最多执行用例数 1000 条（可配置）。
12. 报告默认保留 90 天，可配置保留周期。
